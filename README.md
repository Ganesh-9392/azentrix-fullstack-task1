# Personal Budget Tracker

A full-stack MERN application to track income and expenses.

## Features

- Add Income & Expenses
- Update Transactions
- Delete Transactions
- Monthly Summary Dashboard
- Category-wise Expense Analysis
- Real-time Balance Calculation
- MongoDB Database Integration
- REST API Backend

## Tech Stack

Frontend:
- React.js
- Axios
- Chart.js

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

## API Endpoints

GET /api/transactions

POST /api/transactions

PUT /api/transactions/:id

DELETE /api/transactions/:id
